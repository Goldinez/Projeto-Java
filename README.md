# Jornada Java — Rumo a Back-End Júnior

## Objetivo

Alcançar, em 8 semanas, o repertório técnico e as evidências de trabalho
esperadas de uma pessoa desenvolvedora back-end Java júnior: construir,
testar, documentar e publicar APIs REST com Spring Boot e banco
relacional, de forma autônoma e com código revisável por terceiros.

## Prazo

**8 semanas** — início em 21/09/2026, término em 15/11/2026.
4 horas de estudo por dia, 6 dias por semana (~192h no total).

## Roadmap

| Etapa | Semanas | Foco | Entrega |
|---|---|---|---|
| **0 — Base operacional** | Dias 1–2 | Ambiente, repositório, comunidades e ritual diário definidos | — |
| **1 — Java sólido e persistência crua** | 1–2 | Collections, Streams, exceções, Git avançado, SQL e JDBC | Projeto 1 — CLI de gerenciamento de tarefas, com testes |
| **2 — Spring Boot e API REST** | 3–4 | Spring Boot, Spring Data JPA, DTOs, validação, Postgres em Docker, Swagger | Projeto 2 — API de catálogo, completa e documentada |
| **3 — Projeto principal de portfólio** | 5–6 | Domínio próprio, autenticação JWT, arquitetura em camadas, testes, CI e deploy | Projeto 3 — peça central do portfólio |
| **4 — Empregabilidade** | 7–8 | Refino de portfólio, open source, currículo, simulados, candidaturas | 20 candidaturas enviadas |
